# AamVerse
Interactive marketplace for mangoes and natural products

## 🚀 Live Demo
[Visit AamVerse](https://deek2005.github.io/AamVerse)

## 🏆 Hackathon Project
Built for AamVerse

## 🌟 Features
- 🛒 **Interactive Shopping Cart** - Add/remove items, quantity controls
- 🔍 **Smart Search** - Find products instantly
- 🏷️ **Category Filters** - Filter by Mangoes, Fruits, Oils
- 📱 **Responsive Design** - Works on all devices
- ✨ **Smooth Animations** - Enhanced user experience
- 💰 **Real-time Calculations** - Dynamic pricing and totals

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Icons:** Font Awesome
- **Deployment:** GitHub Pages
